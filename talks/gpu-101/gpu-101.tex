\end{frame}

  \note{우리 행렬은 1024 곱하기 1024이므로 출력 원소가 104만 8576개입니다. thread 하나에 원소 하나를 맡긴다면 논리적인 실행도 그만큼 필요합니다. CUDA는 thread를 block으로 묶고, 이번 커널 실행에 참여하는 block 전체를 grid라고 부릅니다. 여기서는 설명용으로 block 하나에 thread 256개를 넣겠습니다. 그러면 첫 block은 0번부터 255번까지, 다음 block은 256번부터 511번까지를 처리합니다. 전체 원소 수를 256으로 나누면 필요한 block은 4096개입니다. 아래 코드의 꺾쇠 안에는 그 두 숫자가 들어갑니다. add라는 커널을 block 4096개로 실행하되 각 block에는 thread 256개를 넣으라는 뜻입니다. 이렇게 실행할 프로그램과 실행 규모를 지정해서 제출하는 것이 kernel launch입니다. 아직 어느 SM에 어떤 block이 올라갈지는 쓰지 않았습니다. 지금 정한 것은 하드웨어 배치가 아니라 전체 작업의 구성입니다.}
