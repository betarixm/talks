# GPU 101

GPU의 등장 배경부터 CUDA 실행 모델과 메모리 계층까지 다루는 입문 발표.
영어 슬라이드 46장과 한글 발표 대본으로 구성되어 있다.

## 내용

- 그래픽스 파이프라인, 셰이더, GPGPU와 CUDA의 등장
- Thread, warp, block, grid와 SM의 관계
- CPU–GPU 데이터 전송, 캐시, shared memory, 레지스터
- 벡터 덧셈으로 따라가는 커널 실행과 결과 저장
